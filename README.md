# MoviFisio

Landing page de MoviFisio, centro de fisioterapia y rehabilitación en Quito, Ecuador.

## Publicación con GitHub Pages

El workflow de GitHub Actions de este repositorio publica automáticamente el sitio al subir cambios a la rama `main`. En GitHub, configura **Settings → Pages → Build and deployment → Source: GitHub Actions**. Tras finalizar la primera ejecución, el sitio estará disponible en `https://priscilaherreracollantes-ai.github.io/movifisio/`.
